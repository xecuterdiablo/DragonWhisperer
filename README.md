# 🐉 Dragon Whisperer

**Professional Live Stream Transcription & Translation**

## 🚀 Features
- 🎤 Echtzeit-Spracherkennung mit Whisper AI
- 🌐 Mehrsprachige Übersetzung
- 📡 Unterstützt YouTube, Twitch, lokale Dateien
- 🎨 Moderne Dark-UI mit responsive Design
- 💾 Performance-Optimiert mit Caching


## Modell-Auswahl
| Modell | RAM | Geschwindigkeit | Genauigkeit | Empfehlung |
|--------|-----|-----------------|-------------|------------|
| tiny | ~1GB | 🚀 Sehr schnell | 🔴 Gering | Echtzeit |
| base | ~1.5GB | 🚀 Schnell | 🟡 Mittel | Standard |
| small | ~2.5GB | 🟡 Mittel | 🟢 Gut | Qualität |
| medium | ~6GB | 🔴 Langsam | 🟢 Sehr gut | HD-Audio |


## Systemanforderungen
- **Minimum**: 4GB RAM, 2-Core CPU
- **Empfohlen**: 8GB RAM, 4-Core CPU  
- **Optimal**: 16GB RAM, 8-Core CPU + GPU
- 

## ⚡ Schnellstart
1. Installiere Abhängigkeiten: pip install faster-whisper deep-translator tkinter psutil
2. $ python dragon_whisperer.py
3. Stream URL einfügen und START anklicken.
